## How the questions above were settled

**Status: applied to the golden sets on 2026-09-15** (es 362 → 735 judgments, en 370 → 743, and 942 / 985 after the second pass below).

### Four criteria that grade many rows at once

Asked of the author and answered, each time with the option a professional shop would pick. The author then asked that grading doubts like these be settled by the same rules without asking him, so the minor ones below were.

1. **A product of the right type that breaks the query's explicit condition is 0.** "Sin cables", "sin taco", "por menos de 70 euros", "para inducción", "que no ocupe sitio en la mesa": the shopper excluded exactly that product, and this is the query type word matching reads backwards. The half-match rule from the pool (one of two *wanted* conditions = 1) does not apply to an *excluded* one.
2. **Open gift queries are broad, and 3 is kept for the classic gift.** Almost anything giftable counts at 1–2.
3. **A gift that only fits by assuming something about the person is 1.** Cut and size of a garment (even when "padre", "abuela" or "mujer" names a gender), a sport the query does not mention, frailty the query does not mention. A possible answer, never a strong one — it keeps the golden set from rewarding a stereotype.
4. **Another category of the same family is 0 for a query that names a product.** Running clothes for "bambas para correr" or "mochila 8l para correr", a hip pack for "mochila pequeña para correr", tea towels for "escurreplatos". It is the pool's accessory rule applied to the new queries; the 22 original queries were not re-graded.

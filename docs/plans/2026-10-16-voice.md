# Phase 14 · Voice — the plan of the run

**Spec**: `docs/specs/voice.md`, accepted on 2026-10-16 with its seven rulings as
proposed and one addition: every engine and model behind an interface.
Written while Stryker held `src/Search` (phase 13c's owed whole run): every
backend build of this run goes to `--artifacts-path artifacts/voice` until it
ends, so the binaries it is testing are never overwritten.

## Where things live — one decision, taken here and recorded as an ADR

| Piece | Where | Why |
|---|---|---|
| `ISpeechToText`, its options, the fake | `src/AI/Speech/` | `AI` is the port every context reaches a model through (ADR 0053), and a transcriber is a model. No context owns a transcript: it is input, not state |
| The whisper.cpp adapter | `src/AI/Speech/` | Keyed, like the chat profiles; the model it loads is its options |
| `POST /api/speech/transcriptions` | `src/AI/Features/TranscribeSpeech/` | The search box and Tino both use it, so it is neither `Search`'s nor `Assist`'s. `AI` gains its first slice, and Carter finds it as it finds every other |
| The front end's port and adapters | `apps/storefront/src/app/voice/` | One theme folder (ADR 0047): the interface, `web-speech`, `shop`, the microphone component and its store. It moves to a library the day the backoffice speaks |
| The whisper.cpp container | the AppHost, behind `Tendero__Voice=true` | Like Steward's model: off by default, on the GPU when there is one |

## Steps, each closed before the next

1. **V-1a · The back end's port.** `ISpeechToText` (audio and a language in,
   `Heard` out: words, nothing heard, or not available), a deterministic fake, an
   abstract contract suite both inherit, and the slice: size and type limits
   (a short question, not a dictation), anonymous and rate-limited, the audio
   never written anywhere. OpenAPI regenerated, then the front's types.
2. **V-1b · The front end's port.** `SpeechToText` and a `SPEECH_TO_TEXT` token,
   the `web-speech` adapter (on the device only, `processLocally`) and the `shop`
   adapter (the microphone's audio as 16 kHz mono WAV, encoded in the browser,
   no dependency), one contract spec over both with replayed audio.
3. **V-2/V-3 · The microphone.** A mock-up first, for the author: Tino's
   composer and the phone's search box, idle, listening and failed. Then the
   component, the transcript written into the box unsent (`Composer.write`), the
   tokens, the labels in es and en, keyboard and screen reader.
4. **V-4 · The degraded path, tested**: browser specs with the API removed and
   with the server down.
5. **The whisper.cpp server.** The image pinned by tag, the weights converted
   by us from a pinned revision (ADR 0031), sized from a measurement.
6. **V-5 · The measurement.** The author's recordings (about twenty a language),
   a tool over the interface, `docs/analysis/voice-models.md`, and the author's
   choice of default.
7. **Evidence of use**: `voice_input_started`, `voice_transcript_used` in the
   tracking plan.
8. **The close**: Stryker over what the phase touched, the notebook, the book's
   map, the board.
